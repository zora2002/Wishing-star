## Why

目前前端把送出的願望顯示成一條一條的文字清單，放在一個很窄的裝飾星空底下。這跟產品原本設計的手繪稿（`frontend/doc/story.png`）不一樣——稿子畫的是一整片夜空，每則願望是一顆飄過天空的星星，不是清單。純文字清單也讓每則願望看起來都一樣，失去了「許願星」這個產品名稱本來想要的氛圍。

## What Changes

- 把可捲動的願望文字清單，改成星空動畫：每則願望變成一顆星星，緩慢由右往左飄過一整片夜空，不再是文字列。**BREAKING**：拿掉原本一直顯示的「還沒有人許願」提示文字，改成純粹的夜空背景。
- **BREAKING**：整體版面改為置中卡片式構圖——星空面板是一張尺寸有上限的卡片（`max-width:640px; max-height:400px; aspect-ratio:5/4`，直角無圓角），外層頁面背景改用深色放射狀漸層並留白置中；願望輸入表單改成星空卡片下方另一張獨立的旋轉便條紙卡片（暖黃底、陰影、-1.5° 旋轉），不再是原本的圓角 `.wall-card` 外框加「許願牆」標題，也不是前一版「滿版鋪滿視窗、輸入列疊加在場景下方」的做法。
- 新增月亮裝飾，固定顯示在畫面左上角。
- 星星外觀：顏色從 macaron 色票（`frontend/doc/macaron-palette.md`，已更新為 16 色）隨機挑一個；星星圖形改用四芒星 SVG，取代文字符號，並帶有隨機旋轉角度；垂直位置不規則交錯、星星之間出現的間距也隨機，不排成一列或固定網格。
- 滑鼠懸浮互動：滑鼠移到星星上會在星星右側顯示願望詳情文字（純文字、無背景框），內容為「願望 — 名字」（em dash 分隔）。
- 播放佇列：願望依新到舊播放，播放中最舊一則的星星飄出畫面左側後，佇列會回頭重播最新一則。同時最多顯示 7 顆星星；不到 7 則願望時，其餘位置保持空白，不重複播放湊數。願望總數為零時，只顯示夜空與天際線背景，沒有星星也沒有文字。
- 新送出的願望會很快被排進接下來要播放的位置，不用等現有的一整輪播放完——這跟它本來就會排在「新到舊」佇列最前面是一致的。
- 夜空背景改用深藍漸層（取代原本規劃的純黑），並新增一批不對應任何願望、純裝飾用的靜態閃爍背景星點。
- 背景場景：城市天際線剪影改用 SVG path 呈現（邊緣加上柔化的 stroke），並附帶數個暖色調的小型亮燈光點與紋理點點綴，取代原本規劃的 3 個固定白色窗格。
- 輸入表單改成獨立的旋轉便條紙卡片：願望內容欄位在上（滿版寬、置中文字），姓名欄位與送出按鈕在下一列（姓名欄位縮窄），兩欄位維持底線樣式但不再用冒號分隔；送出按鈕圖示從流星改成手繪風紙飛機造型，顏色改用固定色碼 `#b8860b`；畫面文字統一使用 jsdelivr CDN 的手寫風字型 `jf-openhuninn-1.1`（取代先前選用的 Google Fonts Huninn），取代系統字型。
- 送出回饋：願望成功送出後，畫面中央短暫播放一個星星綻放動畫作為回饋，動畫結束後才清空輸入框。
- 即時更新：前端改用遞迴 `setTimeout`（不是 `setInterval`）定期呼叫 `GET /api/wishes`，間隔以十秒為單位，每次都等前一次請求回來才排下一次。瀏覽器分頁不可見時暫停輪詢，恢復可見時再繼續。這樣其他使用者送出的願望，也會以星星的形式出現，不用手動重新整理頁面。
- 願望的資料處理與 API 串接方式（佇列邏輯、輪詢機制、後端呼叫）維持不變，只調整視覺呈現。

以上視覺與動畫細節，比照 `frontend/doc/Make a Wish (standalone).html` 與 `frontend/doc/wishing/`（含 design tokens）這份更新後的參考來源調整。

### Modified Capabilities

## Impact

- `frontend/src/WishBoard.jsx` — 星空面板改為寬高有上限、5:4 比例的卡片（直角無圓角），不再撐滿整個視窗；星星改用 SVG 圖形（含隨機旋轉），新增月亮裝飾與背景裝飾星點，懸浮詳情移到星星右側、無背景框，這些渲染邏輯維持不變，只是外層容器尺寸與定位方式改變。
- `frontend/src/App.css` — 新增頁面外層的深色放射狀漸層背景與置中留白版面、星空卡片的尺寸上限與直角樣式、星星飄動動畫、SVG 天際線與亮燈光點、月亮；新增便條紙表單卡片（暖黃底、陰影、旋轉）、上下堆疊的底線樣式輸入框、紙飛機圖示按鈕樣式；移除 `.wall-card` 外框、`.wish-list`／`.wish` 清單樣式，以及前一版「滿版疊加輸入列＋冒號分隔」的樣式；引入 jsdelivr CDN 的手寫風字型 `jf-openhuninn-1.1`。
- `frontend/src/App.jsx` — 移除 `.wall-card` 外框與「許願牆」標題；版面結構改為「外層置中容器 → 星空卡片 WishBoard → 便條紙表單 WishForm」的上下排列（`WishForm` 不再是絕對定位疊加在 `WishBoard` 上）；把掛載時打一次的 `getWishes()`，換成有分頁可見性判斷的遞迴輪詢迴圈。
- `frontend/src/WishForm.jsx` — 版面改成上下堆疊：願望內容欄位在上（滿版寬），姓名欄位與送出按鈕在下一列，移除冒號分隔；送出按鈕圖示改成紙飛機造型；送出成功後觸發綻放動畫，動畫結束才清空輸入框的行為不變。
- `frontend/src/index.css` — 字型 import 換成 jsdelivr 的 `jf-openhuninn-1.1`（取代先前的 Google Fonts Huninn import）；`body`/`#root` 維持滿版鋪底，改由內層卡片自己控制置中與尺寸上限。
- `frontend/src/starPalette.js` — 色票內容不變（16 色，與 `frontend/doc/wishing/tokens/colors.css` 的 `--star-1..16` 一致），不需修改。
- 後端不用改：現有的 `GET /api/wishes`、`POST /api/wishes` 與 `{id, name, message, createdAt}` 資料結構已經夠用，佇列與輪詢邏輯也不變。
