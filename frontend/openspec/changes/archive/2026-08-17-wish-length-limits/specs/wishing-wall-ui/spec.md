## MODIFIED Requirements

### Requirement: 提交新願望
系統 SHALL 提供姓名與願望內容的輸入欄位，並在使用者送出時建立一則新願望。

#### Scenario: 成功送出願望
- **WHEN** 使用者填寫願望內容（可不填姓名）並按下送出
- **THEN** 系統呼叫後端 API 新增願望，成功後將新願望加入畫面上的列表，並清空輸入欄位

#### Scenario: 願望內容為空
- **WHEN** 使用者在願望內容為空的情況下按下送出
- **THEN** 系統在畫面上顯示「願望內容不能是空的」之類的提示，且不呼叫後端 API

#### Scenario: 願望內容輸入時已達上限
- **WHEN** 使用者在願望內容欄位輸入文字，且內容已達 20 字
- **THEN** 系統阻止再輸入更多字元，欄位內容不會超過 20 字

#### Scenario: 願望內容超過長度限制
- **WHEN** 使用者輸入超過 20 字的願望內容並送出
- **THEN** 系統在畫面上顯示長度超過限制的提示，且不呼叫後端 API

#### Scenario: 未填寫姓名
- **WHEN** 使用者沒有填寫姓名就送出願望
- **THEN** 系統仍正常送出，並顯示後端回傳的預設姓名（例如「匿名的小生物」）

#### Scenario: 姓名超過長度限制
- **WHEN** 使用者輸入超過 6 字的姓名並送出
- **THEN** 系統在畫面上顯示長度超過限制的提示，且不呼叫後端 API

#### Scenario: 送出願望失敗
- **WHEN** 新增願望的 API 呼叫失敗（例如伺服器錯誤）
- **THEN** 系統顯示錯誤提示，保留使用者已輸入的內容，不清空輸入欄位
